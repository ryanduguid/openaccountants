In au-land-tax Section 4.5, RevenueWA land-tax-assessment guidance says 150% of previous unimproved value, but current Land Tax Assessment Act 2002 Glossary clause 6(4)(b)(ii) uses previous taxable value for the ordinary post-2009 cap. Regulation 12A prescribes 150%. The inputs can differ after an earlier cap, so agency summary wording alone is insufficient. Use current unimproved value and previous taxable value for an eligible ordinary lot, then check clause 6 subdivision rules and the section 43A exception separately. Keep a repeated-cap regression case with previous unimproved value 400000 and taxable value 300000: current 900000 caps at 450000, ordinary tax 375 before conditional MRIT. Current statutory compilation 05-m0-01 and regulations 02-f0-00 were checked on 3 November 2026. The guide records the source conflict and does not infer professional approval from passing arithmetic.
