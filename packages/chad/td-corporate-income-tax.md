# Chad Corporate Income Tax

## Corporate income tax (Impôt sur les Sociétés)

- **Corporate income tax (Impôt sur les Sociétés)** — Companies pay Impôt sur les Sociétés (IS) on net taxable profits sourced in Chad, subject to a turnover-based minimum tax. The figures below are a source-cited draft for 2025.
- **Standard corporate tax rate** — 35  _(Code Général des Impôts (Chad) — Impôt sur les sociétés, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Minimum tax (Impôt Minimum Forfaitaire)** — 1.5% of annual turnover, payable if it exceeds the IS otherwise due  _(Code Général des Impôts (Chad) — Impôt Minimum Forfaitaire, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Tax base** — Net taxable profit after deduction of all charges directly entailed by activities taxable in Chad; foreign-source income is excluded  _(Code Général des Impôts (Chad) — IS income determination, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Flat-tax (forfait) regime threshold** — Turnover not exceeding XAF 50,000,000  _(Code Général des Impôts (Chad) — tax regimes, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Simplified regime threshold** — Turnover between XAF 50,000,000 and XAF 500,000,000  _(Code Général des Impôts (Chad) — tax regimes, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Normal regime threshold** — Turnover exceeding XAF 500,000,000  _(Code Général des Impôts (Chad) — tax regimes, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Withholding tax on dividends** — 20% (residents and non-residents)  _(Code Général des Impôts (Chad) — withholding taxes, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Withholding tax on interest (non-resident, outside CEMAC)** — 25  _(Code Général des Impôts (Chad) — withholding taxes, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Withholding tax on registered-bond interest** — 20  _(Code Général des Impôts (Chad) — withholding taxes, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_

- **Withholding tax on service fees (CEMAC companies)** — 7.5  _(Code Général des Impôts (Chad) — withholding taxes, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
- **Withholding tax on royalties (non-resident, petroleum projects)** — 12.5  _(Code Général des Impôts (Chad) — withholding taxes, as reported `[RESEARCH GAP — the statute's text was not read for this change; the secondary summary that carried the figure is no longer cited]`)_
