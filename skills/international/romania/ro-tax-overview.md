# Romania Tax Overview

## The Romanian tax system at a glance

- **Tax year** — Calendar year (1 January to 31 December)  _([Romanian Fiscal Code (Law 227/2015)](https://taxsummaries.pwc.com/romania/individual/tax-administration))_
- **Currency** — Romanian leu (RON)  _(Romanian Fiscal Code (Law 227/2015))_
- **Tax authority** — Agenția Națională de Administrare Fiscală (ANAF — National Agency for Fiscal Administration)  _([Romanian Fiscal Procedure Code (Law 207/2015)](https://www.anaf.ro))_
- **Basis of taxation for residents** — Romanian tax residents are taxed on worldwide income; non-residents are taxed only on Romania-source income  _([Romanian Fiscal Code (Law 227/2015)](https://taxsummaries.pwc.com/romania/individual/income-determination))_
- **Headline personal income tax rate** — 10% percent (flat rate)  _([Romanian Fiscal Code (Law 227/2015)](https://taxsummaries.pwc.com/romania/individual/taxes-on-personal-income))_
- **Standard corporate income tax rate** — 16% percent  _([Romanian Fiscal Code (Law 227/2015)](https://taxsummaries.pwc.com/romania/corporate/taxes-on-corporate-income))_
- **Does VAT exist?** — Yes — VAT (TVA, taxa pe valoarea adăugată); standard rate 21% from 1 August 2025 (was 19%) percent
- **Annual personal income & social contributions return deadline** — 25 May of the following year (Unique Return / Declarația Unică)  _([Romanian Fiscal Code (Law 227/2015)](https://taxsummaries.pwc.com/romania/individual/tax-administration))_
- **Annual corporate income tax return deadline** — 25 March of the following year (Form 101) for calendar-year taxpayers  _([Romanian Fiscal Code (Law 227/2015)](https://taxsummaries.pwc.com/romania/corporate/tax-administration))_
- **EU / VAT regime context** — Romania is an EU member state; VAT follows the EU VAT Directive (intra-Community supplies, OSS/reverse charge apply)  _(EU VAT Directive 2006/112/EC; Romanian Fiscal Code (Law 227/2015))_
