## policyengine-ng

- Repository: [PolicyEngine/policyengine-ng](https://github.com/PolicyEngine/policyengine-ng)
- License: AGPL-3.0
- Stars: 3
- Language: Python
- Scope: A model of the Nigerian tax-benefit system using PolicyEngine Core. Same AGPL-3.0 license — fully compatible.
