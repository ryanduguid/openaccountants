# Moldova Tax Overview

## The Moldovan tax system at a glance

- **Tax year (taxable period)** — Calendar year (1 January - 31 December)  _(Fiscal Code of the Republic of Moldova (Codul Fiscal) — https://taxsummaries.pwc.com/moldova/corporate/tax-administration)_
- **National currency** — Moldovan leu (MDL)  _(Fiscal Code of the Republic of Moldova (Codul Fiscal))_
- **Tax authority** — State Tax Service (Serviciul Fiscal de Stat / Moldovan Tax Administration)  _(Fiscal Code of the Republic of Moldova (Codul Fiscal) — https://taxsummaries.pwc.com/moldova)_
- **Basis of taxation for residents** — Residents are taxed on worldwide income; non-residents on Moldova-source income  _(Fiscal Code of the Republic of Moldova (Codul Fiscal) — https://taxsummaries.pwc.com/moldova/corporate/taxes-on-corporate-income)_
- **Headline personal income tax rate** — 12% percent (flat)  _(Fiscal Code of the Republic of Moldova (Codul Fiscal) — https://taxsummaries.pwc.com/moldova/individual/taxes-on-personal-income)_
- **Headline corporate income tax rate** — 12% percent  _(Fiscal Code of the Republic of Moldova (Codul Fiscal) — https://taxsummaries.pwc.com/moldova/corporate/taxes-on-corporate-income)_
- **Does Moldova levy VAT?** — Yes - standard VAT rate is 20% percent  _(Fiscal Code of the Republic of Moldova (Codul Fiscal), VAT Title — https://taxsummaries.pwc.com/moldova/corporate/other-taxes)_
- **Annual personal income tax return deadline** — 30 April of the year following the reporting year  _(Fiscal Code of the Republic of Moldova (Codul Fiscal) — https://taxsummaries.pwc.com/moldova/individual/tax-administration)_
- **Annual corporate income tax return deadline** — By the 25th day of the third month following the tax period (i.e. 25 March)  _(Fiscal Code of the Republic of Moldova (Codul Fiscal) — https://taxsummaries.pwc.com/moldova/corporate/tax-administration)_
- **VAT return frequency and deadline** — Monthly, due by the 25th of the following month  _(Fiscal Code of the Republic of Moldova (Codul Fiscal), VAT Title — https://taxsummaries.pwc.com/moldova/corporate/other-taxes)_
