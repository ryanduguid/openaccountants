# Texas — OpenAccountants Tax Skills

| Field | Value |
|---|---|
| State | Texas |
| Code | US-TX |
| Income tax | No |
| Sales tax | Yes (6.25% state + up to 2% local) |
| Franchise / gross receipts tax | Yes — Texas Franchise (Margin) Tax |
| Tax authority | [Texas Comptroller of Public Accounts](https://comptroller.texas.gov) |
| Quality tier | Q2 — reviewed content |

## Files in this folder

| File | What it covers |
|---|---|
| `us-tx-franchise-tax.md` | Franchise (margin) tax for taxable entities |
| `us-tx-sales-use-tax.md` | State and local sales & use tax compliance |
| `us-tx-formation.md` | Texas content skill for entity formation covering tax year 2025 |
| `us-tx-margin-tax.md` | Deep content skill for the Texas Franchise (Margin) Tax imposed under Texas Tax Code Chapter 171 |

## What's NOT covered
- Payroll / employer withholding taxes (Texas has no state income tax withholding)
- Property tax (administered at local level)
- Motor vehicle sales tax
- Motor fuels tax
- Hotel occupancy tax
- Insurance premium tax
- Estate / inheritance tax (Texas has none)

## How to use
Upload all `.md` files in this folder PLUS the federal skills from `skills/foundation/` and `skills/federal/` to your LLM. See the main README for details.
