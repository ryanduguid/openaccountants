## What's NOT covered
- Property tax (administered at county level)
- Corporate income / franchise tax (Form 100)
- S-corporation tax (Form 100S)
- Cannabis excise taxes
- Insurance, fuel, and other industry-specific taxes
- Estate / inheritance tax (California has none)

## How to use
Upload all `.md` files in this folder PLUS the federal skills from `skills/foundation/` and `skills/federal/` to your LLM. See the main README for details.
