# Form register

Generated by `scripts/build-form-register.py` — do not edit by hand.

Every form identifier used by **more than one guide** in a jurisdiction,
with the guides that use it. A form named in only one guide is omitted:
it cannot disagree with a sibling.

This exists because silent misuse of a form name is not detectable by
consistency checking — see "Why a checker cannot close this gap" in
[COVERAGE.md](COVERAGE.md). Scan for a form appearing in a guide whose
subject it does not belong to: a rental form in a provisional-tax guide,
a payroll form in a VAT guide. That is the shape the one confirmed
instance took.
